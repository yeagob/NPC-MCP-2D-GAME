# Sistema de Combate - Documentación Técnica

## 📋 RESUMEN EJECUTIVO

### Estado del Sistema
- **Versión**: v1.0 - Sistema Base Completo
- **Estado**: Production Ready
- **Arquitectura**: Component-based + MCP Tools Integration
- **Integración**: 100% compatible con sistemas existentes
- **Funcionalidades**: Ataque, Validaciones, Muerte, Contexto IA

### Características Principales
- **Validación Completa**: Rango 1, orientación obligatoria
- **Animación Dual**: Soporte para animadores izquierdo/derecho
- **MCP Integration**: Tool nativa para NPCs con IA
- **Death System**: Rotación sprite 90°, cambio a DeadBody
- **Context Awareness**: Información de combate en prompts de IA
- **Turn Management**: Remoción automática de personajes muertos

#### Validaciones de Ataque

**IsTargetInRange()**:
```csharp
float distance = Vector3.Distance(
    _characterElement.transform.position,
    target.transform.position
);
return distance <= AttackRange + 0.1f; // 0.1f tolerance
```

**IsFacingTarget()**:
```csharp
// Same cell = always facing
if (Mathf.Abs(directionToTarget.x) < 0.1f && 
    Mathf.Abs(directionToTarget.y) < 0.1f)
{
    return true;
}

// Check horizontal direction match
bool targetIsOnRight = directionToTarget.x > 0;
bool facingRight = _characterElement.FacingDirection == ViewDirection.Right;
return targetIsOnRight == facingRight;
```

#### Sistema de Muerte

```csharp
private void HandleTargetDeath(CharacterElement target)
{
    RotateDeadSprite(target);
    ChangeToDeadBodyType(target);
}

private void RotateDeadSprite(CharacterElement target)
{
    Transform targetTransform = target.transform;
    Vector3 currentRotation = targetTransform.eulerAngles;
    targetTransform.eulerAngles = new Vector3(
        currentRotation.x,
        currentRotation.y,
        DeathSpriteRotation
    );
}

private void ChangeToDeadBodyType(CharacterElement target)
{
    target.SetElementType(MapElementType.DeadBody);
}
```

```csharp
private PromptConfig CreateCombatPromptConfig()
{
    CombatContext combatContext = combatComponent.GetCombatContext();
    
    string attackInfo = combatContext.wasAttackedThisTurn 
        ? $"ALERTA: Has recibido un ataque de {combatContext.attackerName} por {combatContext.damageReceived} de daño." 
        : "No has recibido ataques en este turno.";

    promptConfig.content = $@"ESTADO DE COMBATE:

    SALUD ACTUAL: {combatContext.currentHealth}/{combatContext.maxHealth} HP

    {attackInfo}

    REGLAS DE COMBATE:
    - Solo puedes atacar a personajes adyacentes (1 celda o menos)
    - Debes estar mirando hacia el objetivo para atacar
    - Cada ataque consume 1 punto de acción

}
```

**Integración en ExecuteTurn()**:
```csharp
public override async Task ExecuteTurn()
{
    do
    {
        // Vision prompt
        firstAgent.contextPrompts.Add(visionPromptConfig);
        
        // Inventory prompt
        if (inventoryComponent != null)
        {
            firstAgent.contextPrompts.Add(inventoryPromptConfig);
        }
        
        // Combat prompt
        if (combatComponent != null)
        {
            PromptConfig combatPromptConfig = CreateCombatPromptConfig();
            firstAgent.contextPrompts.Add(combatPromptConfig);
        }
        
        LLMResponse response = await chatOrchestrator.ProcessUserMessageAsync();
        
        missingPoints--;
        
        // Cleanup
        if (combatComponent != null)
        {
            firstAgent.contextPrompts.RemoveAll(p => p.promptId == "combat-status");
            combatComponent.ResetCombatContext();
        }
        
    } while (missingPoints > 0);
}
```

**ExecuteAttack() Refactorizado**:
```csharp
private void ExecuteAttack(CharacterElement target)
{
    if (_combatComponent == null)
    {
        Debug.LogError("CombatComponent not found");
        return;
    }

    AttackResult result = _combatComponent.Attack(target);

    if (!result.success)
    {
        Debug.LogWarning($"Attack failed: {result.errorMessage}");
        return;
    }

    ConsumeActionPoint();
    
    string message = $"Player attacked {target.name} for {result.damageDealt} damage";
    if (result.targetDied)
    {
        message += $" - {target.name} was defeated!";
    }
    
    Debug.Log(message);
}
```

```csharp
public void UnregisterCharacter(CharacterElement character)
{
    int characterIndex = _activeCharacters.IndexOf(character);
    
    // Adjust current turn index if needed
    if (characterIndex < _currentTurnIndex)
    {
        _currentTurnIndex--;
    }
    
    _activeCharacters.Remove(character);
}
```

```csharp
    // Synchronous logic follows
```

### Memory Footprint

- **CombatComponent**: ~100 bytes por personaje
- **CombatContext**: 32 bytes (struct)
- **AttackResult**: 24 bytes (struct)
- **Total per Character**: ~156 bytes

### Escalabilidad

- **Soporta**: Hasta 100 personajes simultáneos
- **Limitación**: Animadores opcionales (no afectan lógica)
- **Turnos**: O(n) donde n = personajes activos

## 🔒 CONSIDERACIONES DE SEGURIDAD

### Validaciones de Combate

- **Prevención de auto-ataque**: target != self
- **Prevención de overkill**: Solo ataca si HP > 0
- **Prevención de exploits de rango**: Distancia calculada en 3D
- **Prevención de ataques ciegos**: Orientación obligatoria

### Sincronización de Estado

- **Contexto limpiado cada turno**: No acumula información obsoleta
- **Estado consistente**: CombatComponent y CharacterElement sincronizados
- **TurnManager autoritativo**: Solo él controla lista de personajes
